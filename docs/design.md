# Refricherator 設計メモ

冷蔵庫をリッチに使い切る。家にある食材から、今日つくる料理を提案するアプリ。

## だれが、いつ使うか

- 使うのはひとり(毎日の献立決め)。まずブラウザで動かし、ホーム画面に置いて使う。最終的に App Store に出す
- 「何を作ろう。期限の近いものから使い切りたい。今日は簡単なのがいい」というとき
- スーパーで「あと何を買えば夕食になるか」を知りたいとき

## 決めたこと(本人と話して決めた)

- 提案は3つの場面:つかれた日(時短)/ 休みの日(気合い)/ お弁当
- 期限の近い食材を優先する。期限は AI が目安を自動で付け、直したいときだけ直す
- 食材の登録はとにかく楽に:レシートを撮る / 買ってきたものを撮る / 話す・打つ / いつものを1回押す
- レシピは AI がその場で書く(冷蔵庫の中身に合わせる)。写真は AI が生成。補足として「似たレシピをネットで見る」
- 提案の3品すべてに写真を出す。月の上限で止める
- 新しく契約するものは増やさない。AI は Gemini だけ(既存のキー)、サーバーは Supabase(無料プラン)
- 見た目は「高級で美しい冷蔵庫を開く」。スマートで、毎日開いてワクワクするもの
- 表示が切れない。画面の切り替えで待たせない(押した瞬間に切り替え、結果は切り替わった先で順に出す)

## 作った側で決めたこと(変えてよい)

- 量(グラム)は管理しない。「作った!」のあとに、使い切ったものを押して消す
- 塩・醤油・油・米などの基本の調味料は、いつも家にあるものとして扱う(登録しない)
- 何人分か・苦手な食材は設定で変える(初期値は1人分)
- ログインは作らない。合言葉を知っている人だけが使える(最初に1回。合言葉入りのリンクを開けば入力もいらない)
- 冷蔵庫は1つだけ(合言葉 = その冷蔵庫)。複数の家庭に対応するのは App Store 版のとき
- よく知られた食材や「いつもの」は AI を呼ばずにすぐ入る。知らない言葉・文章・写真だけ AI が読む
- 文章は速いモデル(約3秒)、写真は安いモデル(1枚およそ5円・約4秒)。どちらも設定で変えられる
- 写真は月180枚(およそ1,000円)で止まり、それ以降は文字だけで動く

## 構成

```
app/                      画面(Vite + React + TypeScript)
supabase/functions/api/   中継サーバー(Supabase Edge Function)
  core.ts                 処理の本体(Supabase にも Gemini にも直接は触らない。テストできる)
  gemini.ts               Gemini の呼び出しと指示文
  serve.ts                Supabase 用の入口(保存先と Gemini をつなぐ)
supabase/migrations/      テーブル
tests/                    単体テスト(vitest)
tools/                    手元用の API、画面の自動テスト
index.html, assets/       公開用に作ったもの(GitHub Pages が main の直下を公開する設定のため)
```

- 公開先:https://kenshingames.github.io/Refricherator/
- Supabase:プロジェクト `refricherator`(東京)。テーブルは `items`(食材)、`recipes`(提案したレシピ)、`kv`(設定・利用数・秘密の値)。どれもアプリからは直接読めず、中継サーバーだけが触る
- Gemini のキーと合言葉は `kv` に入れる(合言葉は元に戻せない形で保存)。キーは手元から中継サーバーに1回だけ送って登録する

## 中継サーバーの受け口

すべて `POST /functions/v1/api`、`x-passcode` に合言葉、本文は `{ action, ... }`。

| action | すること |
|---|---|
| sync | 食材・設定・いつもの・今月の利用数を返す |
| parse | 文章または写真から食材を読み取る(保存はしない) |
| add / update / remove | 食材を足す・直す・なくす |
| suggest | 場面に合わせて3品(または指定の1品)を提案して保存する |
| image | 1品の写真を作って保存する(上限を超えたら作らない) |
| cooked | 作った印を付け、使い切った食材をなくす |
| shopping | 「あと1つ買えば作れる」を返す |
| settings | 設定を保存する |

## 今回の範囲に入れないもの

- App Store への提出(アプリの殻で包むところから別に進める。一般公開の前に、利用回数の制限か課金を決める)
- 電波のない場所での起動、複数人での共有、買い物メモ、お気に入り
